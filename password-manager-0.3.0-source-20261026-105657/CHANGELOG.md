# Cambios

## 0.3.0 — 2026-10-26

Primera preparación para portfolio público, centrada en Windows local.

- Consulta rápida separada de edición, PIN para cada acceso y lápiz circular.
- Bóveda KDBX, guardado automático, historial, copias cifradas y restauración con conservación del archivo anterior.
- Cambio de contraseña maestra/PIN y validaciones compartidas.
- Bloqueo nativo al bloquear sesión de Windows y suspender/reanudar, además de minimizar e inactividad.
- Generación de 20–30 caracteres, símbolos opcionales y portapapeles con limpieza de mejor esfuerzo.
- Demo ficticia, selección de fuentes para publicación, documentación de seguridad y revisión de dependencias.

Sin Android, sincronización, servidor, firma de código ni auditoría externa.
